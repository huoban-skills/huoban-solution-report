# 服务包（报价章节事实底座）

写报告第六章 B 部分与备注时，事实只从本文取，不得改写数字或自造条款。

## 定义与定价

- 服务包是基于零代码平台、教练式交付的服务方式；分教学服务包与搭建服务包，对客户默认指**代搭建服务包**。
- 标准服务包 **¥7,800/包**，每包含 **20 小时专家时间**，计量单位 0.5 小时，可累加购买。
- 有效期与软件订阅周期一致。
- 服务包工时可用于：需求梳理与方案设计、关键功能教学与代搭建、全程陪跑与实操辅导、数据初始化与逻辑验证、专属答疑与复盘。

## 核销机制（备注「服务包起售与核销方式」的素材）

- 每次开始前明确预计消耗并征得确认，服务内容与耗用工时在协作群内同步确认，经企业方验收后核销，剩余工时实时可查。
- 日常简单咨询、资料指引类支持免费不计工时；仅深度参与配置/方案/联调等计入。
- 需求沟通与方案确认所耗时间同样计入工时核销范围。
- 默认线上交付；如需线下，差旅实报实销并从工时中扣减。
- 工时用尽后按需追加采购，不设强制续购。

## 包数建议（按客户复杂度写进报价建议）

| 包数 | 适用 |
| -- | -- |
| 1 包 | 快速验证 / 极简范围 / 团队能力强 |
| 2 包 | 跑通核心流程闭环 / 中等复杂度（推荐起步） |
| 3 包及以上 | 范围广 / 复杂度高 / 接近 ERP、项目管理、AI 深度使用 |

## 与项目制的分界（客户问"为什么不是项目制"时的口径）

服务包适合快速落地与持续优化、按需消耗、启动成本低；跨部门/复杂集成的大型项目适合项目制，服务包模式可随时升级为项目制。
